# IELTS Academic Platform — Specification Package v1.0

Documents are planning artifacts; they do not contain operational code, migrations, trained models, or verified performance results.

1. `01_SRS.md` — consolidated requirements R01–R20; features and acceptance scenarios.
2. `02_AI_Architecture.md` — QR/paper flow, local AI worker, OCR + hybrid evaluator designs.
3. `03_Database_Design.md` — proposed Supabase entities, RLS, relationships and privacy.
4. `04_Evaluation_Protocol.md` — locked holdouts, OCR/Writing metrics, security and release gates.
5. `05_Development_Roadmap.md` — eight implementation phases and quality checkpoints.

Also provided at package root: compiled editable Word and printable PDF.

**Crucial qualifiers:** AI scores experimental and non-official; locally trained OCR performance unknown; free hosting is subject to quota, real-time voice may not be possible at zero ongoing cost; private first, public later. Payments disabled initially. No implementation is authorized by this package.
